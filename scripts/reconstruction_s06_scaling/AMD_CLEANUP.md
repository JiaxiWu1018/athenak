# Session 6 AMD cleanup

The user authorized deletion of the original Session 6 and paired/scaling AMD
trees, conditional on retaining reproduction materials on Perseus.
`amd_cleanup.py` implements that scope. All bulk operations require Slurm.

1. `prepare` inventories both exact AMD roots, freshly hashes retained files,
   and creates complete Git bundles where the AMD source is a Git checkout.
2. `transfer_verify` archives all reproduction inputs, source snapshots,
   protected executables, logs and initialization evidence under the original
   Session 6 `archive/amd_cleanup_20261019/`. It freshly verifies SHA256 of the
   existing Perseus production diagnostics/final restarts against AMD, validates
   actual initial particle states and complete final/300M checkpoint payloads,
   and checks reports, source and reproduction instructions.
3. `delete` requires the hash-bound successful verification receipt, no active
   Session 6 writer jobs, and unchanged complete source inventories. It removes
   only the two fixed campaign roots, retaining an external cleanup receipt.

Existing Perseus diagnostics, reduced data, figures, movies and scientific
manifests are unchanged. Intermediate AMD-only checkpoints and bulk preflight
outputs are deliberately discarded; these states can be regenerated by running
the preserved setup. No new simulation, build, plot or movie is launched.

Paths embedded in historical scripts remain provenance. Reproduction must use
a fresh output root and adapt those paths as documented in the cleanup report.
